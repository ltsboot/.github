# Security Policy

## Reporting a vulnerability

Report vulnerabilities privately through GitHub Security Advisories:

1. Open the **Security** tab of the affected repository.
2. Select **Report a vulnerability**.

Do not open a public issue, pull request, or discussion for a suspected vulnerability.

Include the affected component and version, a description of the impact, steps to reproduce, and a proposed fix if you have one.

## Supported versions

Only the latest release of each line receives security fixes.

| Line | Base | Supported |
|---|---|---|
| Spring Boot 2.7 (ltsboot) | `2.7.18.x` | Yes |
| Spring Framework 5.3 (ltsboot) | `5.3.39.x` | Yes |
| Spring Security 5.7 (ltsboot) | `5.7.14.x` | Yes |

Earlier versions and the upstream commercial releases are not covered by this policy.

## Response process

Security patches are reviewed by a human maintainer before merge and released after review. Response targets by severity are part of the support policy and will be published before the first release.
