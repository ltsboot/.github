# Code of Conduct

ltsboot follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/). Participation in this project's spaces (issues, pull requests, discussions, and other communications) requires following that code of conduct.

Report unacceptable behavior to the maintainers at `security@ltsboot.org`. Reports are reviewed confidentially. Enforcement follows the Contributor Covenant enforcement guidelines.

The full text of the code of conduct is available at https://www.contributor-covenant.org/version/2/1/code_of_conduct/.
